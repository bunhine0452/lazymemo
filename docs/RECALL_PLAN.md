# 필요할 때 다시 펼쳐주는 lazymemo

2026-09-14 · 제품 계획과 첫 구현 명세 · codex

## 제품의 약속

**대충 적어두세요. 필요할 때 다시 펼쳐드릴게요.**

첫 대상은 맥과 아이폰 사이에서 링크·약속·할 일을 흩어 적는 사람이다. 대표 경험은 폰에서 회의 자료를 적고 → 다시 볼 시각을 정하고 → 그 기기에 예약된 알림을 눌러 원문을 열고 → 일을 마치는 흐름이다. 성공은 메모 수가 아니라 “덕분에 놓치지 않은 일”로 확인한다. 종이·크림·포레스트, 가입 없는 파일 소유권, 제목과 분류를 강요하지 않는 입력을 유지한다.

## 결정

사용자가 2026-09-14 시스템 알림의 필요성을 승인했다. 과거의 “알림 권한을 요구하지 않는다”는 원칙을 **첫 실행에 묻지 않고, 사용자가 이 기기에서 알림을 켤 때만 묻는다**로 변경한다.

일정(`at`)과 다시 볼 시각(`surface`)은 구분한다. 별도 시각이 있으면 우선하며 날짜만 있는 메모에는 임의로 아침 알림을 만들지 않는다. 다시 보기 해제는 별도 시각만 제거하므로 일정 시각이 있으면 그때 알린다는 설명을 표시한다. 다 체크한 목록·치워 둔 메모·삭제한 메모는 예약에서 제외한다.

## 첫 출시 구현

1. **선택적 로컬 알림**: 맥·폰 공통 예약 엔진. 기기별 기본 꺼짐, 권한 거절과 예약 실패를 화면에 표시. 예약은 안정적인 메모 ID로 대조하여 수정·미루기·삭제·완료를 반영한다. 알림을 누르면 해당 메모를 연다. 잠금 화면에는 메모 제목이 표시됨을 켜기 전에 설명한다.
2. **메모별 다시 보기**: 현재 시각보다 미래인 날짜와 시간을 직접 지정하거나 한 시간 뒤로 정한다. 일정은 그대로 둔다. 해제·저장 오류가 명확하다. 맥 종이 메뉴와 폰 편집에서 같은 조작을 제공한다.
3. **지금 세 장**: 폰의 전체 목록 위에 오늘 다시 볼 메모 → 오늘 일정 → 고정 메모 순으로 최대 세 장. 이유와 시각을 함께 표시하고 검색·폴더 필터 중에는 숨긴다. 전체 목록과 검색은 유지한다. 시간이 지나면 재평가한다.
4. **신뢰 표시**: 폰에서도 저장소 오류가 보이고, 알림 상태와 예약 수를 확인할 수 있다. iCloud 위치 표시는 동기화 완료 보증으로 표현하지 않는다.
5. **검증**: 예약 제외·정렬·중복 방지·한도·시각 변경·삭제·취소·선정 이유 단위 테스트, 맥과 iOS 빌드, 가능한 시뮬레이터 UI 검증. 실기기 검증 결과는 별도로 기록한다.

## 알려진 운영 경계

- Apple 로컬 알림은 예약 뒤 OS가 전달한다. 집중 모드·알림 설정에 따라 표시와 소리가 달라진다. 정확한 전달 시각을 보장하지 않는다.
- 알림 설정은 **기기별**이다. 양쪽에서 켜면 양쪽에서 울릴 수 있다. 서버 없이 기기 간 전달 여부를 판단하지 않는다.
- 앱이 실행되어 파일 변경을 읽은 기기만 예약을 갱신한다. 폰이 종료된 동안 다른 기기에서 만든/삭제한 메모를 즉시 예약/취소한다고 약속하지 않는다. 공유 시트로 받은 메모도 본 앱이 읽은 뒤 반영된다.
- 첫 판은 가까운 미래 예약 60개를 유지하며 앱 활성화·메모 변경 때 다시 채운다. 한도 초과를 설정에 알린다. 반복 일정은 저장소가 다음 회차로 이동한 뒤 예약한다. 앱을 장기간 열지 않은 상태의 무한 반복은 후속 설계 대상이다.
- 완료한 체크리스트는 즉시 예약에서 빠진다. 일반 글의 완료 여부는 추측하지 않는다.

## 출시 통과 기준

잠긴 아이폰에서 예약 알림 도착, 앱 종료 후 도착, 알림에서 올바른 메모 열기, 권한 거절 뒤 저장 유지, 설정 재허용, 시각 변경과 삭제 후 기존 예약 제거를 실기기에서 확인한다. 맥과 폰을 오가며 오프라인 수정·충돌·재시작 복원을 검증한다. 기존 App Store 플랜의 실기기/샌드박스 검증과 연결하며 확인하지 않은 항목을 완료 처리하지 않는다.

## 다음 제품 실험

10명이 일주일 사용한다. 동의한 사람에게 짧은 인터뷰로 도움이 된 회상 횟수, 불필요한 알림, 입력/검색 혼동, 재사용 의사를 수집한다. 본문을 자동 수집하지 않는다. 10명 중 7명 이상이 도움이 된 구체적 장면을 말하고, 5명 이상이 마지막 이틀에도 자발적으로 쓰는 것을 초기 판단 기준으로 삼는다(시장 성공을 보장하는 수치는 아님).

검증 뒤 위젯·잠금 화면의 빠른 입력, 달력으로 이동할 때 목적지가 보이는 전환, 일 끝내기와 되돌리기를 확장한다. 무조건적인 AI 추천과 위치 자동 알림 확대는 유용성과 방해를 먼저 확인한다. 새 알림의 핵심 경험이 포함된 20초 영상을 만든다.
