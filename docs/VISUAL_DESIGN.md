# lazymemo — 크림과 포레스트

2026-09-12 전면 디자인 개편. 기존 설계 문서의 각진 종이·항상 숨겨진 도구·손그림 달력에 관한 시각 규칙을 대체한다. 메모 저장, 날짜 인식, 서랍의 보관·복원 동작은 유지한다.

## 색과 재질

- 크림색과 따뜻한 차콜을 바탕으로 사용한다. 여섯 메모 색은 기존 대비·색 구분 검증을 유지한다.
- 주요 행동과 오늘 표시는 포레스트 초록 `#295245`, 그 위의 글자는 밝은 크림색이다.
- 다크 모드의 작은 강조 글자는 밝은 세이지로 바꾼다. 버튼 면 색과 글자 색을 구분한다.
- 종이 결과 도트는 낮은 강도로 남긴다. 조작부 그림자는 약하게, 서랍은 내용을 합성한 뒤 그림자를 그려 글자에 그림자가 겹치지 않게 한다.
- 모서리 반경: 본문 카드 14pt, 패널 20pt, 작은 조각 8pt, 컨트롤 10pt.

## 화면별 적용

| 화면 | 변경 |
|---|---|
| 메모 | 부드러운 모서리, 상단 색 표시, 가벼운 표면과 도구 그림자 |
| 달력 | 큰 월 제목, 항상 보이는 월 이동·오늘·닫기, 초록색 오늘 표시, 선명한 일정 제목과 추가 동작, 평평한 구분선 |
| 서랍 | 제목·개수·닫기, 눈에 띄는 검색, 색 표시가 있는 카드, 낮은 강도의 그림자 |
| 빠른 입력 | 앱 아이콘과 같은 두 글줄 마크, 초록 검색 버튼, 확실히 구분되는 주요 행동 버튼 |
| 시작 화면 | 동일한 브랜드와 색, 새로운 문구, 초록색 시작 버튼 |
| 앱 아이콘 | 포레스트 바탕·크림 첫 획·세이지 둘째 획. 기존 코드 기반 렌더링과 macOS 시스템 마스크 유지 |

달력은 5주·6주 전환에도 일정 영역이 흔들리지 않도록 여섯 주의 최소 높이를 예약한다. 서랍은 제목 영역을 창 크기·내부 영역·화면 높이 제한 계산에 함께 반영한다.

## 검증

`scripts/test.sh`의 전체 649개 테스트로 동작·색 대비·팔레트 구분·창 배치를 확인했다. 실제 뷰를 `build/app-polish-ui`에 라이트·다크로 렌더하고, `build/icon/comparison.png`에서 아이콘 크기별 표시를 확인한다. 실행용 번들은 `dist/LazyMemo.app`이다.
