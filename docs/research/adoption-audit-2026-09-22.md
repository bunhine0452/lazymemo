# LazyMemo 유입·설치 조사

조사일: 2026-09-22 KST. 읽기 전용 GitHub API, 공개 검색, 원격 기본 브랜치 소개 원고, 로컬 코드·일지·플래너를 확인했다. 앱 실행 관찰이나 사용자 인터뷰는 하지 않았다.

## 결론

가장 강한 신호는 GitHub 배포 경로의 극히 작은 유입과 다운로드다. 제품 만족도나 재사용 실패는 현재 자료로 판정할 수 없다. 설치 경로 개선과 실제 대상 사용자 관찰이 기능 추가보다 우선이다.

## 설치와 소개의 장애물

1. 원격 기본 브랜치 `site/ko/index.html`은 `data-store="soon"`이다. 스토어 버튼이 숨겨지고 심사 중이라고 표시된다. 공개 TestFlight 참여 링크도 해당 원고에서 찾지 못했다. 로컬 플래너에는 심사 제출이 미완이다. 실제 App Store Connect 심사 상태는 확인하지 못했으므로 미출시를 확정하지 않는다.
2. 첫 화면은 Homebrew 두 줄과 GitHub 릴리스 링크를 제공한다. README와 소개 원고는 GitHub 판이 미공증임을 명시한다. 다운로드한 바이너리의 실제 서명은 검증하지 않았다. 비개발자가 쉽게 설치할 경로에 마찰이 있다는 가설은 강하다.
3. 원격 원고는 최신 공개 릴리스가 0.9.3인데도 0.9.0이 오늘 나왔다고 말한다. macOS/iOS 26 이상 제한도 명시한다. 지원 범위가 좁지만 그로 인한 이탈 비율은 알 수 없다.
4. 원격 소개 순서는 철학·시연 다음 테마, 웹 비서, 종이 크기, 위젯 등이다. 움직임 구현 용어 quick/settle/fly까지 소개한다. 방문자가 해결하려는 상황보다 제작 결과 설명에 무게가 있다는 편집상 판단이다. 로컬에는 비서를 뒤로 옮긴 변경이 있지만 원격 원고에는 아직 반영되지 않았다. Pages 실제 응답은 웹 도구로 가져오지 못했으므로 원격 원고와 실제 배포본의 동일성은 확정하지 않는다.

## 발견 가능성과 첫 경험

- `"lazymemo" "bunhine0452"`, `"lazymemo" 메모 앱` 검색에서 이 프로젝트의 뚜렷한 결과를 확보하지 못했고, 동명 Windows 메모 앱 https://getlazymemo.com/ 및 결제 독촉 서비스 https://lazymemo.com/ 가 반환됐다. 제한된 검색 결과이며 전체 검색 색인·검색 순위의 증거는 아니다. 이름만으로 찾기 어려울 가능성이 있다.
- 로컬 Mac 안내는 5단계이며 앞 두 단계의 연습 입력은 저장되지 않는다. iPhone 안내도 5장이고, 첫 장에서 입력·날짜·검색·모델 질문을 함께 설명한다. 양쪽 모두 건너뛰기는 있다. 실제 자기 메모 작성보다 학습이 앞서는 부담은 가설이며 이탈을 직접 관찰한 것은 아니다.
- 로컬 개인정보 문서는 분석·추적·크래시 리포터가 없다고 명시한다. 활성 사용자·첫 메모 전환·다음 날 재사용률을 여기서 계산할 수 없다. TestFlight/ASC 사용 지표는 이번 조사에서 확보하지 못했다.
- 플래너 `lazymemo-recall#recall-field`의 사용자 10명 일주일 검증은 아직 미완이다. 이번 조사로 그 항목이 완료된 것은 아니므로 상태를 바꾸지 않는다.

## 다음 검증 순서

1. 실제 ASC 상태와 소개 문구를 맞추고, 일반 사용자가 바로 설치 가능한 경로 하나를 확보한다. GitHub 직접 배포는 공증 여부를 실제 산출물로 검증한다.
2. 소개 첫 화면의 한 상황을 좁힌다. 예: “작업 중 떠오른 할 일, 창을 바꾸지 않고 적고 필요한 때 다시 보세요.” 15초 시연은 입력→저장→다시 보기 한 흐름만 보여준다.
3. 지원 OS를 쓰고 메모를 자주 잊는 사람 5~10명에게 직접 관찰한다. 설명 없이 설치, 실제 자기 메모 1개 저장, 다음 날 재사용 여부와 이유를 기록한다. 외부 연락은 이번 조사에서 보내지 않았다.
4. 첫 입력을 실제 저장하고 그 결과 위에서 필요한 조작을 설명하는 방향을 시험한다. 기존 연습 공간을 바꾸기 전 실제 혼란을 관찰한다.
5. 기존 프라이버시 약속을 유지하며 GitHub 집계·스토어 집계·동의한 인터뷰로 유입과 재사용을 분리한다. 새 추적 코드를 임의로 넣지 않는다.
