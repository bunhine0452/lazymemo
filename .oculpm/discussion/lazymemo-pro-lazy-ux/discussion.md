## 문제 정의

lazymemo 의 존재 이유는 **"사용자는 게으르다"**는 전제다. 하지만 현재 버전은 다음과 같은 3가지 본질적인 한계에 직면해 있다:

1. **게으른 사용자의 4대 마찰점 잔존**:
   - **입력 마찰**: 여전히 창을 띄우고 직접 타이핑해야 한다 (클립보드 즉시 투척, 화면 위 드래그 앤 드롭, 전역 우클릭 서비스 미지원).
   - **인지 부하**: 여러 장의 메모가 바탕화면에 쌓였을 때 '지금 당장 해야 할 1가지'를 집중시키지 못하고 시각적 피로를 준다.
   - **휘발성 낙서의 파편화**: 전화번호·계좌번호 같은 1회용 낙서가 메모 창 하나씩을 차지해 금방 창 상한(24개)에 부딪힌다.
   - **검색의 단어 기억 강요**: "지난주 목요일에 본 그 링크", "어제 적은 영수증"처럼 시간/맥락으로 찾고 싶은 게으른 사용자의 기억 모델을 지원하지 못한다.

2. **아이콘과 UI의 '아마추어 / AI 생성물' 느낌 탈피 필요**:
   - AI 생성 아이콘 특유의 이질감(불필요한 네온 그라데이션, 인공적인 광택, 비정형적인 3D 왜곡, 비표준 곡률)을 철저히 배제해야 한다.
   - macOS HIG(Human Interface Guidelines)를 완벽히 준수하는 **물리적 고급 종이 질감(Tactile Cotton Paper), 정밀 애플 초타원(Squircle Grid), 다중 레이어 소프트 앰비언트 섀도우(Multi-tier Ambient Occlusion), 정교한 마이크로 타이포그래피**를 갖춘 프로페셔널 디자인 언어로 도약해야 한다.

3. **Claude MCP 연동의 게으른 확장**:
   - Claude Desktop 사용자뿐만 아니라, 로컬에서도 1-클릭으로 "지저분한 메모 합쳐줘", "오늘 할 일 1개만 골라줘" 같은 작업을 원터치로 수행할 수 있어야 한다.

## 후보 해결 방안

### 방안 A — 초저마찰 캡처: 클립보드 원키 투척 & 유니버설 드롭 {#opt-zero-friction-capture}
- **내용**:
  1. `⌥⌘V` (단축키 1회): 클립보드에 복사된 텍스트/이미지를 입력 팝오버 없이 바탕화면 새 메모나 '오늘의 낙서장'에 즉시 꽂아 넣음.
  2. 어느 앱에서든 드래그: 브라우저 링크, 이미지 파일, Finder 텍스트 파일을 바탕화면의 종이나 메뉴바 아이콘 위로 드롭하면 바로 첨부/기록.
  3. macOS 시스템 서비스(`Services` 메뉴): Safari나 터미널에서 텍스트 드래그 후 우클릭 $\rightarrow$ "lazymemo에 기록".
- **장점**: 타이핑과 창 전환 마찰을 0으로 만들어, 가장 게으른 순간(웹서핑 중 복사, 캡처)에 메모가 남는다.
- **단점**: 클립보드 자동 인식 시 원치 않는 데이터가 쌓이지 않도록 명시적 단축키 또는 HUD 피드백 필요.
- **비용**: 중간 (AppKit 드래그 앤 드롭 타깃 + 서비스 확장).

### 방안 B — 오늘의 낙서장(Daily Scratchpad) & 단일 포커스 모드 {#opt-daily-scratchpad-focus}
- **내용**:
  1. **Daily Scratchpad**: 메모를 무한정 새로 만들지 않고, 하루 동안의 단발성 메모(전화번호, 주소, 임시 텍스트)를 단 한 장의 종이에 시간순 append. 자정이 지나면 자동으로 일일 보관함으로 정리.
  2. **1-Thing 포커스 모드**: 바탕화면에 10장의 메모가 널브러져 있을 때, 단축키나 클릭 한 번으로 '오늘 가장 중요한 1개 메모'만 남기고 나머지를 부드럽게 반투명 처리/숨김.
- **장점**: 게으른 사람이 겪는 '메모 파편화'와 '선택 마비(ADHD 패럴리시스)'를 동시에 해결.
- **단점**: 일반 메모와의 UI적 구분이 명확해야 함.
- **비용**: 낮음 (기존 `Tidy` 및 `layout.json` 구조 활용 가능).

### 방안 C — 프로페셔널 Native macOS 아이콘 & UI 룩앤필 전면 개편 {#opt-pro-native-design}
- **내용**:
  1. **App Icon (Apple Tahoe/Sonoma HIG 준수)**:
     - 캔버스: macOS 1024x1024 정규 규격 베이스플레이트 + 정밀 5차 초타원(Squircle).
     - 재질: 따뜻한 웜 톤의 고급 코튼 페이퍼(300g 두께감)가 살짝 기울어져 레이어링된 형태.
     - 디테일: 상단 탑다운 라이팅(90° 입사각)에 의한 섬세한 엠보싱 에지, 정밀한 1px 내부 베벨 하이라이트, 실제 종이 모서리가 아주 미세하게 접힌 부분의 섀도우, 딥 네이비(Dark Indigo) 만년필 잉크 흡수 자국.
     - 인공적인 AI 광택/형광 사이버 그라디언트를 100% 제거하고, Apple 시스템 앱(Notes, TextEdit, Pages)보다 한 단계 더 우아한 문구류(Stationery Craft) 감성 부여.
  2. **Desktop Note UI Polish**:
     - 그림자: 단일 검정 그림자 대신 2중 섀도우(1px 접촉 섀도우 + 24px 확산 앰비언트 섀도우)로 바탕화면 배경화면이 무엇이든 부드럽게 떠오르는 질감.
     - 컨트롤러: 평소에는 완벽한 종이 글씨만 보이고, 마우스 호버 시에만 40% 투명도로 아주 절제된 초소형 액션 버튼(치우기, 미루기, 달력) 표시.
  3. **다크 모드 전용 흑연/차콜 페이퍼 팔레트**:
     - 단순 흑백 반전이 아닌, 웜 다크 차콜 톤(#1E1E24) 위에 크림 미색 잉크(#F4EAD4)가 부드럽게 스미는 야간 데스크 감성.
- **장점**: "AI가 대충 그린 앱" 느낌을 100% 제거하고, Apple Design Award 수상작 수준의 세련됨 확보.
- **단점**: 코드로 모든 레이어 렌더링 수치를 정밀하게 튜닝해야 함.
- **비용**: 중간 (수학적 렌더링 코드 튜닝 및 `scripts/make-icon.swift` 개편).

### 방안 D — 퍼지 맥락 검색 (Fuzzy Contextual Browsing) {#opt-fuzzy-temporal-search}
- **내용**:
  - 빠른 입력 창에서 단어를 기억하지 못하는 사용자를 위해 시간/형태 기반 스마트 칩 제공:
    - `@오늘`, `@어제`, `@이번주`, `@링크`, `@체크리스트`, `@사진`
  - 스페이스바 탭 시 팝업 창 안에서 즉시 전체 본문을 프리뷰(Quick Peek).
- **장점**: 정확한 검색어를 입력하기 귀찮은 게으른 사용자가 방향키 2번만으로 지난 기록을 복원.
- **단점**: 검색 인덱스 쿼리 로직 확장 필요.
- **비용**: 낮음~중간.
