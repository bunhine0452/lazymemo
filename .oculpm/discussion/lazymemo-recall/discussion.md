## 문제 정의

lazymemo 의 약속은 「대충 적어두세요. 필요할 때 다시 펼쳐드릴게요」다. 그런데 「다시 펼쳐 준다」가 지금까지는 **맥 바탕화면의 종이가 앞으로 나오는 것**뿐이었고(`DueClock`), 폰에는 그마저 없었다. 컴퓨터 앞에 없는 사람에게 적힌 시각은 그냥 지나갔다. 사용자는 2026-09-14 시스템 알림이 필요하다고 승인했다.

결정할 것: 시스템 알림을 **어디에, 어떤 동의로, 무엇을 걸며, 무엇을 약속하지 않을지.** 제약은 이 앱이 이미 적어 둔 것들이다 — 첫 실행에 아무것도 묻지 않는다(README 프라이버시 절) · 서버가 없다 · 메모는 iCloud 파일이라 기기 간에 흐른다 · 날짜만 있는 메모의 시각을 지어내지 않는다.

## 후보 해결 방안

### 방안 A — 지금대로, 종이만 {#opt-paper-only}
- 장점: 권한 0, 배울 것 0. 이미 있다.
- 단점: 폰에는 종이가 없어 아무것도 안 온다. 맥도 자리를 비우면 끝. 약속을 못 지킨다.
- 비용: 0.

### 방안 B — 기기별 선택적 로컬 알림 {#opt-local-optin}
- `UserNotifications` 로컬 예약. 기본 꺼짐, 「이 기기에서 알림 받기」를 켤 때만 시스템이 묻는다. 켜짐은 `UserDefaults` — 파일로 번지지 않는다.
- 저장소가 바뀔 때마다 있어야 할 예약 집합(`Recall.reservations`)과 OS 큐를 대조한다. 메모 id 가 예약 id 라 수정·미루기·삭제·완료가 같은 자리를 찾는다.
- 장점: 서버 없음 · 밖으로 나가는 것 없음 · 동의가 기기 안에 머문다 · 맥의 종이와 같은 `surfacesAt` 을 본다.
- 단점: 앱이 파일을 읽은 기기만 예약을 갱신한다 — 폰이 꺼진 동안 맥에서 적은 것은 폰이 다시 읽어야 걸린다. 양쪽 켜면 양쪽 울린다. iOS 는 예약 64개 한도.
- 비용: 공통 패키지 하나(`LazyMemoReminders`), 맥 창 하나, 폰 시트 둘, 폰 「지금」 띠.

### 방안 C — 서버 푸시 {#opt-push}
- 장점: 기기 간 동기화된 알림, 한 번만 울리게 조정 가능.
- 단점: 서버와 계정이 생긴다 — 「가입도 계정도 없다」와 프라이버시 표를 깬다. 메모 제목이 서버를 지난다.
- 비용: 이 앱의 정체를 바꾼다.

## 결론

**방안 B.** 로컬 알림은 이 앱의 약속(서버 없음·첫 실행에 묻지 않음·파일 소유권)을 하나도 깨지 않으면서 폰에 「다시 펼쳐 준다」를 준다. 기기 간 동기화된 알림은 약속하지 않고, 그 경계를 설정 화면과 README 에 적는다. 위젯·잠금 화면 입력·사용자 검증은 `docs/RECALL_PLAN.md` 의 다음 단계다. 진척은 `.oculpm/planner/lazymemo-recall.md`.
