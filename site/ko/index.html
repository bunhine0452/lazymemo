종이가 여덟 벌입니다. 고르면 이 페이지가 그 종이로 바뀝니다.

앞선 판의 종이는 한 벌이었습니다. 지금은 여덟 벌이고, 무엇을 고르든 메모·달력·서랍·홈 화면의 위젯이 전부 그 종이에 인쇄됩니다. 이 페이지도 같습니다 — 아래의 여덟 중 하나를 누르면 바탕도, 도트 그리드도, 초록도, 호박색도 그 자리에서 함께 바뀝니다.

종이가 바꾸는 것

  • 바탕·목록의 종이·잉크·보조 잉크
  • 강조색 — 면으로 쓸 때와 종이 위의 글자로 쓸 때

바꾸지 않는 것

  • 여백 다섯 단계와 글자 층 넷의 비율
  • 모서리 반경 — 카드 14 · 패널 20 · 컨트롤 10 · 조각 8
  • 과녁 크기, 그리고 움직임의 속도
  • 지우기의 붉은색, 달력의 주말 색

지우기가 어느 종이에서나 붉고 토요일이 파란 것은 취향이 아니라 약속이기 때문입니다 — 되돌아오지 않는 쪽으로 가는 버튼과, 한국 달력을 읽는 방식. 종이를 바꿨다고 그것을 다시 배우게 할 수는 없습니다. 둘은 종이가 어두운지만 따라 밝기를 뒤집습니다.

직접 고를 수도 있습니다. 설정 → 테마 → 「직접 고르기」에 네 가지가 있습니다 — 강조색, 종이에 스미는 색, 글자 크기, 종이 결. 고른 색은 쓰기 전에 바닥 위로 되끌어 올립니다 (WCAG AA — 본문 4.5:1, 보조 3:1). 색을 고르는 자유가 자기 메모를 못 읽게 만드는 자유일 수는 없습니다.

여덟 중 둘은 빛 모드에서도 어두운 종이입니다. 미드나잇과 숲속 어둠은 외관에게 묻지 않고 스스로 「어둡다」고 말하므로, 종이의 가장자리도 그림자도 잉크도 함께 뒤집힙니다 — 위에서 둘 중 하나를 눌러 보면 이 페이지가 같은 일을 합니다. 여덟 벌 × 네 외관 = 서른두 벌에서 종이 위의 글 여덟 자리가 전부 바닥 위인지는 눈이 아니라 시험이 잽니다.

「지금」은 앱의 띠 그대로입니다 — 오늘 다시 볼 것 · 오늘 일정 · 고정한 것을 다가오는 시각부터. 「다음 약속」은 시각이 적힌 것 중 가장 가까운 한 장이고, 가는 길을 적어 두었으면 둘째 줄이 언제 나가 무엇을 타는지 말합니다. 아니면 남은 시간이 흐릅니다. 「달력」은 이번 달, 오늘은 동그라미 · 일정 있는 날은 점. 「적기」는 누르면 펜이 올라옵니다.

줄머리의 3pt 색 획 하나가 「이게 어느 메모인지」를 말합니다 — 색은 가장자리와 잉크로만 드러나고 카드를 통째로 물들이지 않습니다 (설계문서 §14.4). 「봤어요」는 홈 화면에서 그대로 눌립니다 — 앱을 열지 않고 카드가 내려가고, 앱에서도 함께 내려갑니다. 큰 「지금」은 체크리스트 카드 밑에 아직 안 한 칸을 달고, 누르면 그 자리에서 체크됩니다 — 파일에 적혀 맥의 종이에서도 체크돼 있습니다. 넷 다 잠금 화면 가족이 있고, 고른 종이를 따라가며, 앱과 같은 마크다운 파일을 읽습니다 — 인덱스도 서버도 없습니다. 위젯은 App Store 판에 있습니다.   • 다시 보기

    칸을 전부 체크한 목록과 「완료」한 것은 사흘 뒤, 지난 일정은 그다음 날이 끝나면 바탕화면에서 빠집니다. 지운 것이 아닙니다 — 메뉴가 「치워 둔 N장」이라 적어 두고 하나씩도 도로 꺼냅니다. 날짜가 지났다고 끝난 것은 아닙니다: 칸이 남은 목록, 도로 꺼낸 것, 미래에 다시 보기로 한 것, 고정한 메모는 건드리지 않고, 놓친 것은 「놓친 N장」으로 남습니다.

물어보세요. 메모에 없으면 웹을 읽어 정리해 남깁니다.

미리보기입니다. 메모에서 답 찾기와 시키기는 이 기기 안에서 끝나지만, 웹의 답은 키 없는 공개 웹 검색(DuckDuckGo)에 기댑니다 — 공식 API 가 아니라 언제든 끊길 수 있고, 끊기면 앱이 그렇다고 말합니다. 「웹에서 찾기」를 누르거나 「웹에서 …」라고 말할 때만 나가고, 그 전에는 아무 데도 접속하지 않습니다.

「치과 언제였지?」를 ✦ (맥은 ⌥⌘↵) 로 보내면 답은 당신의 메모에서 나오고, 그 밑에 근거가 된 원문 줄이 그대로 붙습니다. 그냥 남기면 그 물음도 메모가 됩니다 — 적기는 늘 적기입니다. 메모에 없으면 상자가 「웹에서 찾기」를 권합니다 — DuckDuckGo 에 키도 계정도 없이 물은 말 한 줄만 나가고, 이어서 앱이 앞의 세 쪽 본문을 읽어 서로 견준 뒤에 답합니다. 문장마다 누르면 열리는 출처가 붙습니다.

그리고 묻습니다 — 메모로 남길지, 정리해서 남길지, 이미 있는 메모에 붙일지. 정리한 메모에는 자리가 정해져 있습니다: 제목 · 답 한두 문장 · 「핵심」 · 값이 여럿이면 「세부」 표 · 「출처」. 틀은 앱이 들고 모델은 가운데만 씁니다 — 그래야 작은 모델이 제목을 두 번 적거나 주소를 지어내지 않습니다. 모델이 넘어져도 앱이 발췌로 같은 자리를 채웁니다.

메모는 나가지 않습니다. 나가는 것은 물은 말 한 줄뿐입니다. 메모에서 답 찾기와 시키기는 언제나 이 기기 안에서, 한 번 받아 둔 모델(Gemma 4 E2B, 2.6GB)이 합니다. GitHub 맥 판에서 claude 명령이 이 컴퓨터에 있으면 셋 — 웹의 답 · 다듬기 · 정리 — 만 그것을 빌립니다. 키는 여전히 어디에도 없습니다.

미리보기입니다. 대중교통 길찾기는 네이버 지도 웹의 공개 길찾기에 키 없이 묻습니다 — 공식 API 가 아니라 언제든 끊길 수 있고, 끊기면 앱이 그렇다고 말합니다. 되물음에 답할 때만 나가고, 설정에서 묻지 않게 끌 수 있습니다.

지도 링크와 시각을 한 줄에 붙여 두면 — 「금요일 저녁 6시반 밥약속」 — 적힌 뒤 「가는 길」이 권해지고, 누르면 「어디서 출발하시나요?」 하고 묻습니다 (누르기 전엔 다음 글이 새 메모입니다). 역 이름이든, 주소든, 다른 지도 링크든, 「지금 여기」든 답하면 길을 찾아 버스 · 지하철 · 택시를 분과 요금과 함께 내밉니다. 고른 길은 메모 끝에 적힙니다 — 노선과 방면, 타는 곳, 환승, 요금, 그리고 늦지 않게 나가는 출발 시각. 출발 10분 전에 종이가 나오고 배너가 무엇을 탈지 말합니다.

  1. 적기 지도 링크와 시각을 한 줄에. 자리는 알아서 풀립니다.
  2. 출발지 「강남역」 — 주소도, 「지금 여기」도 됩니다.
  3. 고르기 버스 · 지하철 · 택시, 분과 요금. 갈아타는 길은 그렇다고 말합니다.
  4. 출발 경로 카드가 메모에 서고, 배너가 나갈 시각을 말합니다.

대중교통은 네이버 지도 웹의 길찾기가 키 없이 답하고, 택시는 애플 지도의 어림입니다. 되물음에 답하기 전까지는 아무 데도 접속하지 않습니다 — 「됐어」면 아무것도 나가지 않고, 어느 쪽이든 메모 본문은 나가지 않습니다.

당신이 시키지 않으면 아무것도 나가지 않습니다.

우리 서버도, 계정도, 분석 도구도 없습니다. 이 기기에서 나갈 수 있는 것은 아래가 전부입니다.

메모 파일 전부당신의 iCloud「iCloud 로 동기화…」를 직접 누를 때만
메모 한 장의 본문ClaudeGitHub 판만 — MCP 를 직접 등록했을 때, 또는 ✧ 를 누를 때마다
물은 말 한 줄DuckDuckGo, 그리고 결과 앞의 세 쪽웹에서 찾을 때만. 메모는 나가지 않고, 세 쪽은 쿠키 없이 한 쪽에 8초·1MB 로 읽습니다
장소 이름 하나, 또는 좌표 하나애플 지도 · 네이버 지도자리 카드가 설 때와 「어디서 출발하시나요?」에 답할 때. 「됐어」면 아무것도 안 나갑니다
주소 하나그 사이트, 또는 GitHub링크를 카드로 펼칠 때와 새 판 확인. 둘 다 끌 수 있습니다
아무것도—다시 보기 알림 · Spotlight · 이 기기의 비서가 메모에서 답을 찾는 일

이 기기의 모델은 「받기」를 직접 누를 때 한 번 Hugging Face 에서 내려받습니다 — 그때 나가는 것은 파일 요청뿐입니다. 모델은 iCloud·백업 밖 앱 폴더에 있고 같은 화면에서 지울 수 있습니다. 권한을 묻는 자리는 다섯이고 첫 실행에는 하나도 없습니다. 전부는 개인정보 처리방침에 적혀 있습니다.

이 페이지도 같은 약속을 지킵니다. 바깥으로 나가는 요청이 하나도 없습니다 — 추적기도, 웹폰트도, CDN 도 없고, 영상과 그림은 페이지와 같은 자리에서 옵니다. 위의 여덟 벌도 그림이 아니라 CSS 입니다. 배포 워크플로가 바깥 자원이 하나라도 있으면 빌드를 떨어뜨립니다.

받기.

Homebrew

두 줄이면 됩니다. 그 뒤로는 앱이 새 판을 스스로 알려 줍니다. Claude 연동과 자체 업데이트는 이 판에만 있습니다.

brew tap bunhine0452/lazymemo
brew install --cask lazymemo

소스에서 빌드

Xcode 없이 빌드됩니다 — Command Line Tools 면 충분합니다. 코드를 읽는 사람에게는 이쪽이 가장 정직한 길이고, 직접 지은 앱에는 격리 딱지가 애초에 붙지 않습니다.

git clone https://github.com/bunhine0452/lazymemo
cd lazymemo
./scripts/build-app.sh
