lazymemo
화면 메모 파일 Claude GitHub English

적어 둔 자리에
그대로 있는 메모.

macOS 바탕화면에 상주하는 메모와 달력입니다. 정리하기 싫어하는 마음을 전제로 설계했습니다.

그래서 정리를 부탁드리지 않습니다. 열어야 할 앱이 없고, 새 메모는 ⌥⌘N 한 번으로 시작되며, 저장 버튼이 없습니다.

macOS 26 (Tahoe) 이상 번들 2.6MB 계정도 로그인도 없음 MIT 라이선스

Homebrew

사실 두 줄입니다 — 탭을 더하고, 그다음 cask 를 받습니다. 그 뒤로는 갱신을 Homebrew 가 맡습니다.

brew tap bunhine0452/lazymemo
brew install --cask lazymemo

소스에서 빌드

Xcode 없이 빌드됩니다 — Command Line Tools 면 충분합니다. 저희가 가장 권해 드리는 길입니다.

git clone https://github.com/bunhine0452/lazymemo
cd lazymemo
./scripts/build-app.sh

먼저 말씀드릴 것이 하나 있습니다. 이 앱은 아직 공증받지 않았습니다. 내려받은 앱에는 검역 딱지가 붙고, macOS 15 부터는 딱지가 붙은 미공증 앱이 그냥 「손상되었습니다」로 끝납니다. 그래서 cask 가 설치 직후 그 딱지를 떼어 냅니다. 조용히 떼는 대신 이렇게 적어 두는 편을 택했습니다 — 미봉책이고, Developer ID 를 받는 날 사라집니다. 그 처리가 미덥지 않으시다면 소스에서 직접 빌드해 주세요. 직접 빌드한 앱에는 애초에 딱지가 붙지 않습니다. 그 선택은 전혀 이상하지 않으며, 그쪽도 계속 1차 경로로 둡니다.

왜 이렇게 생겼는지

  • 완성을 요구하지 않습니다

    쓰다 만 것, 제목 없는 것, 날짜 없는 것이 여기서는 정상 상태입니다. 채워 달라고 기다리는 빈칸도, 채우라는 표시도, 잊어버릴 저장 버튼도 없습니다.

  • 시간이 유일한 구조입니다

    폴더도 태그도 두지 않습니다. 그래서 달력이 만지는 물건입니다 — 일정을 집어 다른 날에 놓고, 한 번 눌러 미룹니다. 내일 3시 치과 라고 적으시면 날짜는 앱이 읽습니다.

  • 오래된 것은 스스로 물러납니다

    다 체크한 목록과 지난 일정은 조용히 바탕화면에서 빠집니다. 지운 것이 아닙니다 — 메뉴가 몇 장인지 적어 두고, 한 번에 도로 꺼내실 수 있습니다.

  • 앱이 앞에 나서지 않습니다

    가만히 있는 메모는 글자와 종이뿐입니다. 머리글도 아이콘 줄도 색 점도 없고, 조작은 포인터가 올 때 내용 위에 떠올랐다가 포인터가 떠나면 함께 물러납니다.

화면

쓰는 법

⌥⌘N 빠른 입력. 메뉴바 아이콘 밑에 말풍선으로 뜹니다. 치시면 기존 메모가 함께 걸러집니다. 단축키는 메뉴 → 설정에서 바꾸실 수 있습니다.
⌥⌘V 클립보드 즉시 메모. 복사해 두신 글이나 사진이 창을 열지 않고 바로 새 종이가 됩니다.
⌘⌫ 목록에서 고른 메모를 지웁니다. 상자는 닫히지 않고 바로 아래 줄에 되돌리기가 생깁니다.
esc 닫기. 적던 글은 상자가 기억합니다 — 다시 열면 그대로 있고 전부 선택돼 있어, 그냥 치시면 덮어써집니다.
메모의 × 숨기기입니다. 삭제가 아닙니다. 메뉴에서 언제든 다시 꺼내실 수 있습니다.
붉은 휴지통 지웁니다. 종이는 그 자리에 남아 8초 동안 「되돌리기」를 들고 있고, 그 뒤로도 30일 안에 되돌리실 수 있습니다.
달력 아이콘 날짜가 없는 메모를 달력에 놓습니다. 날짜가 이미 있으면 그 일정이 달력의 어디에 있는지 펼쳐 보여 드립니다.
달력의 일정 줄 하루 미루거나, 날짜를 떼어 바탕화면 종이로 돌려보내거나, 지웁니다. 셋 다 아래에 되돌리기가 남습니다.

끝난 것은 스스로 물러납니다. 칸을 전부 체크한 목록은 마지막으로 손대신 지 사흘 뒤, 지난 일정은 그 다음 날이 끝나면 바탕화면에서 빠집니다. 지운 것이 아닙니다 — 파일에도 검색에도 달력에도 그대로 있고, 메뉴가 「치워 둔 N장」이라고 적어 둡니다. 고정해 두신 메모는 이 규칙이 건드리지 않습니다.

메모는 파일입니다

lazymemo 를 지우셔도 메모는 남습니다. 정본은 사용자 컴퓨터에 있는 마크다운 파일이고, Finder 로 여셔도 다른 텍스트 에디터로 고치셔도 괜찮습니다.

~/Documents/lazymemo/
  notes/2026/08/01K3ZQ….md   ← 정본
  .trash/                     ← 삭제한 메모 (30일 보존)

이 폴더를 iCloud Drive 안으로 옮기시면 동기화가 됩니다. 가입할 백엔드도 설정할 것도 없고, 폴더를 옮기시면 앱이 따라갑니다 (메뉴 → 설정).

Claude 연동 (선택입니다)

lazymemo 는 MCP 서버를 함께 빌드합니다. 등록하시면 Claude Desktop 에서 「다음 주 화요일 오후 2시에 치과 예약 잡아줘」 나 「이번 달 일정 뭐 있어?」 처럼 말씀하실 수 있습니다.

API 키는 필요 없습니다. lazymemo 가 Claude 를 부르는 것이 아니라 Claude 가 lazymemo 를 부르는 방향이라, 토큰 비용은 사용자의 Claude 구독이 부담합니다. 이 연동은 전적으로 선택이고, 직접 등록하시기 전에는 꺼져 있습니다.

Claude 가 메모를 지울 수 있기 때문에, 영구 삭제하는 도구는 아예 만들지 않았습니다. 이건 규칙이 아니라 배선입니다 — MCP 서버가 닿을 수 있는 코드에 하드 삭제 함수 자체가 없습니다. 삭제는 .trash/ 로 옮기는 것까지이고, 되돌리기는 호출 한 번입니다.

프라이버시

메모 본문이 컴퓨터 밖으로 나가는 경로는 위의 MCP 연동뿐이고, 그것도 직접 등록하셔야 열립니다.

네트워크를 쓰는 곳이 하나 더 있습니다 — 링크를 카드로 펼치기 입니다. 붙이신 주소의 제목과 그림을 가져오려고 그 주소에 접속합니다. 나가는 것은 주소 하나뿐이고 메모 본문은 아니지만, 어느 사이트를 붙이셨는지는 그 사이트가 알게 됩니다. 설정에서 끄실 수 있고, 끄시면 이 앱은 아무 데도 접속하지 않습니다.

이 페이지도 같은 약속을 지킵니다. 바깥으로 나가는 요청이 하나도 없습니다 — 추적기도, 웹폰트도, 분석 스크립트도 없고, 배포 워크플로가 내보내기 전에 그것을 실제로 검사합니다.
