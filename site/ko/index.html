0.4 서랍에 폴더가 생겼습니다

적어 둔 자리에 그대로 있는 메모.

macOS 바탕화면에 상주하는 메모와 달력입니다. 정리하기 싫어하는 마음을 전제로 설계했습니다.

그래서 정리를 부탁드리지 않습니다. 열어야 할 앱이 없고, 새 메모는 ⌥⌘N 한 번으로 시작되며, 저장 버튼이 없습니다. 내일 오후 3시 치과 라고 적으면 날짜는 앱이 읽습니다.

설치하기 릴리스 보기

macOS 26 (Tahoe) 이상 번들 3.6MB 계정도 로그인도 없음 MIT 라이선스

Homebrew

두 줄입니다 — 탭을 더하고, cask 를 받습니다. 그 뒤로는 갱신을 앱이 스스로 알려 드립니다.

brew tap bunhine0452/lazymemo
brew install --cask lazymemo

소스에서 빌드

Xcode 없이 빌드됩니다 — Command Line Tools 면 충분합니다. 저희가 가장 권해 드리는 길입니다.

git clone https://github.com/bunhine0452/lazymemo
cd lazymemo
./scripts/build-app.sh

먼저 말씀드릴 것이 하나 있습니다. 이 앱은 아직 공증받지 않았습니다. 내려받은 앱에는 검역 딱지가 붙고, macOS 15 부터는 딱지가 붙은 미공증 앱이 그냥 「손상되었습니다」로 끝납니다. 그래서 cask 가 설치 직후 그 딱지를 떼어 냅니다. 조용히 떼는 대신 이렇게 적어 두는 편을 택했습니다 — 미봉책이고, Developer ID 를 받는 날 사라집니다. 그 처리가 미덥지 않으시다면 소스에서 직접 빌드해 주세요. 직접 빌드한 앱에는 애초에 딱지가 붙지 않습니다.

왜 이렇게 생겼는지

  • 완성을 요구하지 않습니다

    쓰다 만 것, 제목 없는 것, 날짜 없는 것이 여기서는 정상 상태입니다. 채워 달라고 기다리는 빈칸도, 채우라는 표시도, 잊어버릴 저장 버튼도 없습니다.

  • 시간이 유일한 구조입니다

    바탕화면의 종이는 분류를 묻지 않습니다. 달력이 만지는 물건입니다 — 일정을 집어 다른 날에 놓고, 한 번 눌러 미룹니다. 폴더는 밀어 둔 뒤의 서랍 안에만 있습니다.

  • 오래된 것은 스스로 물러납니다

    다 체크한 목록과 지난 일정은 조용히 바탕화면에서 서랍으로 내려갑니다. 지운 것이 아닙니다 — 서랍을 열면 거기 있고, 한 번에 도로 꺼내실 수 있습니다.

  • 앱이 앞에 나서지 않습니다

    가만히 있는 메모는 글자와 종이뿐입니다. 조작은 포인터가 올 때 내용 위에 떠올랐다가 포인터가 떠나면 함께 물러납니다. 알트탭에도 독에도 서지 않습니다.

화면

서랍과 폴더

바탕화면 한구석에 「서랍 N」 탭이 앉아 있습니다. 종이의 × 를 누르거나 탭 위로 끌어다 놓으면 들어가고, 안은 이름 있는 폴더로 나뉩니다. 폴더에 넣는 것은 곧 서랍에 넣는 것이고, 꺼낸 종이도 이름표는 그대로라 다시 넣으면 같은 칸으로 돌아갑니다.

전체 13장보기 4읽을 것 3집 4+ 새 폴더

쓰는 법

⌥⌘N 빠른 입력. 메뉴바 아이콘 밑에 말풍선으로 뜹니다. 치시면 기존 메모가 함께 걸러지고, 첫소리로도 찾습니다. 단축키는 메뉴 → 설정에서 바꾸실 수 있습니다.
⌥⌘V 클립보드 즉시 메모. 복사해 두신 글이나 사진이 창을 열지 않고 바로 새 종이가 됩니다.
esc 닫기. 적던 글은 상자가 기억합니다 — 앱을 껐다 켜도, 판을 갈아도 남습니다. 다시 열면 전부 선택돼 있어 그냥 치시면 덮어써집니다.
메모의 × 서랍에 넣습니다. 삭제가 아닙니다. 우클릭하면 폴더를 골라 바로 넣을 수 있습니다.
붉은 휴지통 지웁니다. 종이는 그 자리에 남아 8초 동안 「되돌리기」를 들고 있고, 그 뒤로도 30일 안에 되돌리실 수 있습니다.
달력 아이콘 날짜가 없는 메모를 달력에 놓습니다. 날짜가 이미 있으면 그 일정이 달력의 어디에 있는지 펼쳐 보여 드립니다.
서랍에서 ↑↓ Tab ⏎ 목록을 훑고, 옆 폴더로 넘어가고, 짚은 줄을 펼칩니다. ⌘⏎ 꺼내기, ⌘⌫ 지우기, esc 는 한 겹씩 되돌립니다.

끝난 것은 스스로 물러납니다. 칸을 전부 체크한 목록은 마지막으로 손대신 지 사흘 뒤, 지난 일정은 그 다음 날이 끝나면 바탕화면에서 서랍으로 내려갑니다. 지운 것이 아닙니다 — 파일에도 검색에도 달력에도 그대로 있습니다. 고정해 두신 메모는 이 규칙이 건드리지 않습니다.

메모는 파일입니다

lazymemo 를 지우셔도 메모는 남습니다. 정본은 사용자 컴퓨터에 있는 마크다운 파일이고, Finder 로 여셔도 다른 텍스트 에디터로 고치셔도 괜찮습니다.

~/Documents/lazymemo/
  notes/2026/09/01K3ZQ….md   ← 정본. 폴더 이름표도 이 안의 한 줄입니다
  .trash/                     ← 삭제한 메모 (30일 보존)

이 폴더를 iCloud Drive 안으로 옮기시면 동기화가 됩니다. 가입할 백엔드도 설정할 것도 없고, 폴더를 옮기시면 앱이 따라갑니다 (메뉴 → 설정). 아이폰에서는 단축어 하나로 그 폴더에 .md 를 떨어뜨리면 앱이 받아 앉힙니다.

Claude 연동 (선택입니다)

lazymemo 는 MCP 서버를 함께 빌드합니다. 등록하시면 Claude Desktop 에서 「다음 주 화요일 오후 2시에 치과 예약 잡아줘」, 「이번 달 일정 뭐 있어?」, 「장보기 폴더에 우유 넣어 줘」 처럼 말씀하실 수 있습니다.

API 키는 필요 없습니다. lazymemo 가 Claude 를 부르는 것이 아니라 Claude 가 lazymemo 를 부르는 방향이라, 토큰 비용은 사용자의 Claude 구독이 부담합니다. 이 연동은 전적으로 선택이고, 직접 등록하시기 전에는 꺼져 있습니다.

Claude 가 메모를 지울 수 있기 때문에, 영구 삭제하는 도구는 아예 만들지 않았습니다. 이건 규칙이 아니라 배선입니다 — MCP 서버가 닿을 수 있는 코드에 하드 삭제 함수 자체가 없습니다. 삭제는 .trash/ 로 옮기는 것까지이고, 되돌리기는 호출 한 번입니다.

프라이버시

메모 본문이 컴퓨터 밖으로 나가는 경로는 위의 MCP 연동뿐이고, 그것도 직접 등록하셔야 열립니다.

네트워크를 쓰는 곳이 둘 더 있습니다 — 링크를 카드로 펼치기(붙이신 주소 하나가 나갑니다)와 새 판이 나왔는지 물어보기(GitHub 에 주소 하나, 판 번호도 안 보냅니다). 둘 다 설정에서 끄실 수 있고, 끄시면 이 앱은 아무 데도 접속하지 않습니다.

이 페이지도 같은 약속을 지킵니다. 바깥으로 나가는 요청이 하나도 없습니다 — 추적기도, 웹폰트도, 분석 스크립트도 없고, 영상도 이 페이지와 같은 자리에서 옵니다. 배포 워크플로가 내보내기 전에 그것을 실제로 검사합니다.
