lazymemo

macOS 바탕화면에 상주하는 메모 + 캘린더.
사용자는 게으르다를 전제로 설계했다.

앱을 «열어서» 쓰지 않는다. 메모는 항상 바탕화면에 떠 있고, 새 메모는 ⌥⌘N 한 번으로 시작되며, 저장 버튼이 없다.

Homebrew

한 줄로 설치한다.

# macOS 26 (Tahoe) 이상
brew tap bunhine0452/lazymemo
brew install --cask lazymemo

소스에서 빌드

Xcode 없이 빌드된다. 이쪽이 1차 배포 경로다.

git clone https://github.com/\
bunhine0452/lazymemo.git
cd lazymemo
./scripts/build-app.sh

이 앱은 아직 공증받지 않았다. 그래서 cask 는 설치 뒤 검역 딱지를 떼어 낸다 — 미봉책이고, Developer ID 를 받는 즉시 사라진다. 믿을 수 없다면 소스에서 직접 빌드하는 쪽이 맞다. 그렇게 만든 앱에는 애초에 딱지가 붙지 않는다.

왜 이렇게 생겼나

  • 완성을 요구하지 않는다

    쓰다 만 것, 제목 없는 것, 날짜 없는 것이 정상 상태다. 빈칸도, 채우라는 표시도, 저장 버튼도 없다.

  • 시간이 유일한 구조다

    폴더도 태그도 유지하지 않는다. 그래서 달력이 만지는 물건이다 — 일정을 집어 다른 날에 놓고, 한 번 눌러 미룬다. 내일 3시 치과 라고 적으면 앱이 알아서 날짜를 읽는다.

  • 오래된 것은 스스로 물러난다

    다 체크한 목록과 지난 일정은 조용히 바탕화면에서 빠진다. 지운 것이 아니다 — 메뉴가 «치워 둔 N장» 이라고 적어 둔다.

  • 앱은 자기를 드러내지 않는다

    기본 상태의 메모는 글자와 종이뿐이다. 머리글도 아이콘 줄도 없고, 조작은 포인터가 올 때 내용 위에 겹쳐 뜬다.

화면

메모는 파일이다

lazymemo 를 지워도 메모는 남는다. 정본은 당신 컴퓨터의 마크다운 파일이고, Finder 로 열어도 텍스트 에디터로 고쳐도 된다.

~/Documents/lazymemo/
  notes/2026/08/01K3ZQ….md   ← 정본
  .trash/                     ← 삭제한 메모 (30일 보존)

이 폴더를 iCloud Drive 안으로 옮기면 동기화가 된다. 별도 백엔드가 없고, 옮기면 앱이 따라간다 (메뉴 → 설정).

Claude 연동 (선택)

lazymemo 는 MCP 서버를 함께 빌드한다. 등록하면 Claude Desktop 에서 «다음 주 화요일 오후 2시에 치과 예약 잡아줘» 라고 말할 수 있다.

API 키가 필요 없다. lazymemo 가 Claude 를 호출하는 것이 아니라 Claude 가 lazymemo 를 호출하는 방향이라, 토큰 비용은 당신의 Claude 구독이 부담한다.

Claude 가 메모를 지울 수 있으므로 영구 삭제하는 도구를 아예 만들지 않았다. 이건 규칙이 아니라 배선이다 — MCP 서버가 호출할 수 있는 코드에 하드 삭제 함수 자체가 없다.

프라이버시

메모 본문이 컴퓨터 밖으로 나가는 경로는 위의 MCP 연동뿐이고, 그건 직접 등록해야 켜진다.

네트워크를 쓰는 곳이 하나 더 있다 — 링크를 카드로 펼치기. 본문에 붙인 주소의 제목과 그림을 가져오려고 그 주소에 접속한다. 나가는 것은 주소 하나뿐이고 메모 본문은 아니지만, 어느 사이트를 붙였는지는 그 사이트가 알게 된다. 설정에서 끌 수 있고, 끄면 이 앱은 아무 데도 접속하지 않는다.

이 페이지도 같은 규칙을 지킨다 — 바깥으로 나가는 요청이 하나도 없다. 추적기도, 웹폰트도, 분석 스크립트도 없다.
